MAKE LINKS TRANS transgender link from the botw the link TRANSGENDER LINK

(A Kettu plugin that transforms links, e.g. from x.com -> hotyurisex.com.)

Configurable rules, e.g.:
- Source Domain: `instagram.com`
- Target Domains (comma-separated): `oginstagram.com`
- Keep Parameters (comma-separated): `img_index`
